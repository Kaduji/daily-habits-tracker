# Daily Habits – मेरी अच्छी आदतें (Android APK गाइड) 📱✨

यह ऐप दैनिक सकारात्मक आदतें बनाने, स्ट्रीक्स (निरंतरता) ट्रैक करने और दैनिक रिमाइंडर प्राप्त करने के लिए बनाया गया 100% हिंदी हैबिट ट्रैकर है।

---

## 🌟 ऐप की मुख्य विशेषताएं
- **दैनिक आदत ट्रैकिंग:** सुबह का योग, पानी पीना, पढ़ाई, टहलना आदि।
- **स्ट्रीक एवं प्रगति चार्ट:** साप्ताहिक और मासिक निरंतरता ग्राफ।
- **दैनिक रिमाइंडर:** समय पर नोटिफिकेशन और अलर्ट।
- **100% गोपनीयता:** आपका डेटा केवल आपके डिवाइस में सुरक्षित रहता है (नो क्लाउड ट्रैकिंग)।
- **डेटा बैकअप:** कभी भी एक क्लिक में JSON बैकअप और रीस्टोर।
- **थीम चयन:** आकर्षक लाइट और डार्क मोड।

---

## 🚀 असली Android APK प्राप्त करने के २ आसान तरीके

### तरीका १: GitHub Actions से बिना कंप्यूटर के सीधे APK डाउनलोड करें (सबसे सरल व अनुशंसित) ⭐
यदि आपके पास कंप्यूटर नहीं है, या आप Android Studio का भारी सेटअप नहीं करना चाहते:

1. **GitHub पर जाएं:** [GitHub.com](https://github.com) पर अपना मुफ्त खाता खोलें और एक नई रिपॉजिटरी (New Repository) बनाएं।
2. **प्रोजेक्ट कोड अपलोड करें:**
   - ऐप की सेटिंग्स में जाकर **"प्रोजेक्ट फाइल्स (ZIP) डाउनलोड करें"** पर क्लिक करें।
   - ज़िप फ़ाइल को अनज़िप करें और सभी फाइलों को अपने नए GitHub रिपॉजिटरी में अपलोड (Push) कर दें।
3. **ऑटोमैटिक बिल्ड चालू:**
   - रिपॉजिटरी में `.github/workflows/build-apk.yml` फ़ाइल पहले से शामिल है।
   - जैसे ही आप कोड अपलोड करेंगे या GitHub के **Actions** टैब में जाकर **"Run workflow"** दबाएंगे, GitHub के क्लाउड सर्वर पर 2 मिनट में APK बनना शुरू हो जाएगा।
4. **APK डाउनलोड करें:**
   - बिल्ड पूरा होने पर (ग्रीन टिक मार्क दिखने पर) उस रन पर क्लिक करें।
   - नीचे **Artifacts** सेक्शन में जाएं और **`DailyHabits-Hindi-Debug-APK`** पर क्लिक करके सीधे डाउनलोड करें।

---

### तरीका २: अपने कंप्यूटर पर Android Studio के साथ APK बनाएं 💻

#### आवश्यक सॉफ्टवेयर:
- **Node.js** (v18 या v20)
- **Java JDK 17 या 21**
- **Android Studio** (Ladybug या कोई भी आधुनिक संस्करण)
- **Android SDK Platform 34 या 35**

#### चरणबद्ध निर्देश:
1. **टर्मिनल / कमांड प्रॉम्प्ट में प्रोजेक्ट डायरेक्टरी खोलें:**
   ```bash
   cd daily-habits-tracker
   ```

2. **डिपेंडेंसीज इनस्टॉल करें:**
   ```bash
   npm install
   ```

3. **वेब कोड कंपाइल करें और Android फोल्डर सिंक करें:**
   ```bash
   npm run build:android
   ```

4. **Android Studio में प्रोजेक्ट खोलें:**
   ```bash
   npx cap open android
   ```
   *(या Android Studio खोलकर `Open Existing Project` चुनें और `android` फोल्डर चुनें)*

5. **Gradle Sync होने दें:**
   - Android Studio पहली बार आवश्यक लाइब्रेरीज़ डाउनलोड करेगा। इसमें 1-2 मिनट लग सकते हैं।

6. **APK तैयार करें:**
   - ऊपर मेनू बार में जाएं: **Build → Build Bundle(s) / APK(s) → Build APK(s)**
   - कुछ ही सेकंड में नीचे दाईं ओर **"APK(s) generated successfully"** का संदेश आएगा।
   - **locate** लिंक पर क्लिक करें।

7. **तैयार APK फ़ाइल का स्थान:**
   ```text
   android/app/build/outputs/apk/debug/app-debug.apk
   ```

## 📲 APK को अपने मोबाइल में कैसे इनस्टॉल करें

1. अपने कंप्यूटर या GitHub से डाउनलोड की गई **`app-debug.apk`** फ़ाइल को अपने फोन में ट्रांसफर करें (WhatsApp, Telegram, Google Drive या USB केबल द्वारा)।
2. अपने फोन का **Files / File Manager** ऐप खोलें और **Downloads** फोल्डर में जाएं।
3. **`app-debug.apk`** फ़ाइल पर टैप करें।
4. यदि आपका फोन सुरक्षा संदेश दिखाए कि अज्ञात ऐप ब्लॉक हैं:
   - **Settings** पर टैप करें।
   - **"Allow from this source"** (इस स्रोत से इंस्टॉल करने की अनुमति दें) को चालू करें।
5. वापस आकर **Install (इनस्टॉल करें)** बटन दबाएं।
6. ऐप सफलतापूर्वक इंस्टॉल हो जाएगा और आपके होम स्क्रीन पर ऐप का आइकॉन आ जाएगा!

## 🔒 सुरक्षा एवं अनुमतियां (Permissions)
- **INTERNET & ACCESS_NETWORK_STATE:** केवल वेब संसाधनों और भविष्य के ऑनलाइन सिंक के लिए।
- **POST_NOTIFICATIONS:** आपकी आदतों के समय पर दैनिक रिमाइंडर नोटिफिकेशन भेजने के लिए।
- **VIBRATE:** रिमाइंडर बजने पर कंपन के लिए।
- **पूर्ण गोपनीयता:** कोई भी डेटा किसी अज्ञात सर्वर पर नहीं भेजा जाता।
